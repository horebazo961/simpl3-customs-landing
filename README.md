## Deploy

Este repositorio está preparado para **Cloudflare Pages**:

1. En Cloudflare Dashboard → Workers & Pages → Create → Connect to Git
2. Selecciona el repositorio `horebazo961/simpl3-customs-landing`
3. Build settings: Framework preset = None (o Static)
4. Build command: (dejar vacío)
5. Output directory: `/` (o vacío)
6. Deploy

La URL pública será del tipo `https://simpl3-customs-landing.pages.dev` (o el nombre que elijas).
